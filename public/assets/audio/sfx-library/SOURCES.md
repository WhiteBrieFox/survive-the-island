# Sound effect sources

## Mixkit

The MP3 candidates in this folder were downloaded from Mixkit's free sound
effect catalogue on 2026-10-10. They are included here for in-project review
under the Mixkit Sound Effects Free License.

Source groups:

- Water, sea and swimming
- Ship hull and wood
- Cards, UI confirmations and success cues
- Whooshes, monster vocals, rumble and explosion

## Kenney

The OGG candidates are selected from Kenney's "Impact Sounds" pack version 1.0.
The pack is released under Creative Commons Zero (CC0).

Original pack:
https://kenney.nl/assets/impact-sounds

Before production release, keep this file with the project and re-check the
current source license pages as part of the release checklist.
