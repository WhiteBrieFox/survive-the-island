## 海绵 BGM 提示词

### 统一音乐方向

所有曲目整体保持明亮、欢快、富有冒险感。即使进入危机和终局，也通过速度、切分节奏和更密集的明亮打击乐提升紧迫感，不使用阴沉恐怖、持续低频压迫、悲壮合唱或黑暗电影配乐风格。音乐应让玩家感到热闹、刺激和想继续行动，而不是焦虑或沉重。

### 大厅

```text
纯音乐，可无缝循环。原创手工微缩海岛冒险桌游大厅音乐，明亮、欢快、好奇、欢迎朋友加入。
马林巴、轻木打击乐、尤克里里式拨弦、温暖木管、很轻的海浪质感。
无歌词、无人声、无合唱、无明显主旋律引用，不要电影预告片重击。
节奏适合玩家聊天，90-120 秒，结尾与开头自然衔接。
```

### 前期探索

```text
纯音乐，可无缝循环。热带远征正在顺利进行，明亮欢快，海岛震动带来一点俏皮的紧张。
马林巴、手鼓、拨弦、木管和弹性贝斯，旋律积极，危险只通过轻微加速和短促节奏暗示。
不抢对白，无歌词，无人声，120-180 秒。
```

### 危机

```text
纯音乐，可无缝循环。岛屿大面积沉没，木筏争夺和海中生物逼近，但整体依旧明亮、欢快、充满游戏感。
更密集的手鼓、马林巴切分、弹性贝斯、明亮铜管短句和木质敲击，用速度制造刺激，不用阴暗低频制造恐怖。
保持朋友聚会桌游的趣味和可重复聆听，无歌词，无人声，120-180 秒。
```

### 火山终局

```text
纯音乐，可无缝循环。第三座火山即将爆发的最终逃生阶段，明亮、飞快、热闹，像一场欢乐但争分夺秒的最后冲刺。
快速手鼓、马林巴与木琴跑动、急促拨弦、弹性贝斯和明亮铜管，不使用深沉压迫的鼓点或恐怖音色。
紧迫、英勇、家庭友好、带一点胜负揭晓前的兴奋，无合唱、无歌词，60-120 秒。
```
