# 实现状态

更新日期：2026-10-08

## 已完成

- 单端口 Fastify + Socket.IO 生产服务、6 位房间码和可选密码。
- 2 至 5 名真人或 AI 混合组局；AI 提供休闲与策略两档。
- 任意观战者、玩家与观战者断线恢复、服务重启快照恢复。
- 轮流放置探险者和木筏；2 人双颜色与 5 人叠放设置。
- 步行、游泳限制、木筏容量、控制权、空筏移动和登筏选择。
- 行动、水位上涨、生物三个阶段；无人待救时按回合起始状态翻两格。
- 三类生物逐格移动、提前停止、攻击、驱逐剂响应和巨兽推离选择。
- 40 块地形的准确地貌与背面分布、全部即时效果和五种能力。
- 第三座火山、无人待救、宝藏计分与并列胜利。
- 隐藏宝藏、能力和地形背面按身份过滤；公开事件不带私密 payload。
- 服务器事件日志、房间快照和修订号冲突校验。
- 3D 微缩棋盘、桌面与手机 HUD、合法目标高亮和阶段提示。
- Mira 主菜单原创插画；海绵生成大厅、探索、危机、终局 BGM、海洋环境层和短音效。
- BGM、环境音、音效独立音量，首次交互解锁并在页面失焦时暂停。
- 14 条规则回归；2、3、4、5 人 AI 对局均可自动跑到结束。
- Chrome 桌面与手机观战截图、刷新恢复和 Canvas 可见性验收。

## 已知残余

- 3D 生物和地形仍以程序化原创模型为主，Mira 已完成主菜单图，但尚未替换为完整定制低模资产包。
- 策略 AI 有风险与目标启发式，但还不是搜索型高强度 AI。
- 自动测试尚未做到“每个背面效果各一条独立测试”，浏览器端也未覆盖所有多人同时操作排列。
- 键盘替代棋盘操作和色觉辅助仍需专项无障碍验收；系统“减少动态效果”偏好已接入。
- 首次创建/加入及大厅席位变更会使用一次恢复刷新，以规避当前 React 19 + Chrome 154 的外部回调提交问题。
- 客户端主包约 1.27 MB，后续可拆分 Three.js 相关 chunk。

强制验收项仍以 `docs/production-acceptance.md` 为准；上述残余关闭前不标记为商业发布版。
