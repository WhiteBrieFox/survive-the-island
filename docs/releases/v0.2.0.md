# 沉岛远征 v0.2.0：昼夜远征

发布日期：2026-10-10

## 本次重点

这次更新集中改善对局信息的可读性、岛屿下沉反馈、时间氛围和结束体验。移动路线现在可以提前估算，地块沉没拥有完整动画，每一步行动都能在航海日志中追溯；远征结束后，原本简单的获胜提示也升级为完整结算报告。

## 路线规划虚线

- 所有陆地与水域格增加浅色六边形虚线轮廓。
- 虚线保持低透明度，不遮挡地形模型、人物、生物和合法目标高亮。
- 玩家可以直接按格子数量提前规划步行、游泳、木筏和生物移动路线。
- 水域与陆地采用不同高度，避免虚线穿过地形或产生明显悬空感。

## 地块下沉动画

- 翻格后先显示醒目的地块标记，再播放翻转和下坠过程。
- 地块下沉时伴随轻微抬升、翻面、旋转、缩小和水花扩散。
- 单次动画约持续 1.72 秒，让所有玩家都能明确看到具体沉没位置。
- 动画播放期间锁定新的翻格请求，避免连续点击导致多个动画重叠。
- 服务端状态更新后仍保留原地形模型完成动画，不会瞬间消失。

## 详细航海日志

- 游戏界面展示最近 5 条事件，并可点击任意事件查看详情。
- 完整日志支持按时间倒序浏览，记录事件编号和精确时间。
- 详情会明确说明玩家操作了哪个单位、从哪里移动到哪里以及消耗或结算结果。
- 覆盖探险者移动、游泳、获救、木筏移动与沿途登筏、地块下沉、火山、漩涡和能力牌。
- 覆盖生物骰、生物出现与移动、鲨鱼和海蛇攻击、驱逐剂响应、巨兽推离与登筏联动。
- 手机端提供独立日志入口和全屏日志布局。

## 规则说明修正

- 海蛇攻击不能使用驱逐剂。
- 驱逐剂只可响应鲨鱼或巨兽攻击。
- 规则页、能力牌说明和攻击响应提示保持一致。
- 对应生物不存在或没有合法移动目标时，可以跳过生物移动。

- 顶部状态栏会显示当前时刻与阶段，所有玩家看到的进度保持一致。

## 全新胜利结算

- 展示获胜者、最高宝藏、远征轮数、总获救人数、总宝藏和结束原因。
- 展示完整排行榜，并正确处理并列得分与共同胜利。
- 点击任意玩家可查看个人远征报告。
- 个人报告包括获救率、获救、失踪、未归队、移动次数、下沉地块、生物操控和能力牌使用次数。
- 保留查看完整航海日志和返回大厅操作。
- 桌面端一屏呈现核心信息，手机端采用可滚动内容和固定底部操作区。
