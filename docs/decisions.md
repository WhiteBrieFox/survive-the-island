# 已确认决策

方案已于 2026-10-08 确认，进入实现阶段。

## 推荐默认方案

1. **规则版本**：严格采用 2024 版 `Survive The Island`。
2. **产品定位**：朋友间非商业联机，使用原创暂定名和原创视听资产。
3. **技术栈**：React + React Three Fiber + Fastify + Socket.IO + TypeScript。
4. **联机方式**：单机启动、单 TCP 端口、房间码加可选密码。
5. **画面方向**：明亮手工微缩景观，危险但不血腥。
6. **首发平台**：桌面 Chrome/Edge/Safari 优先，平板可玩，手机为次优体验。
7. **首版范围**：包含观战与 AI 玩家；不做账号、匹配、语音和文字聊天。
8. **存档**：服务端自动快照，服务重启后可恢复最近房间。
9. **回合时间**：默认不限时，可由房主开启 60/90/120 秒计时。
10. **断线规则**：暂停当前玩家计时并等待重连；房主可在 3 分钟后跳过其回合。

## 已确认

- 按 2024 版规则实现。
- 采用“手工微缩景观 + 灾难电影式动态”。
- 观战与 AI 玩家纳入首版。
- 当前按朋友间私用设计；公开发布或商业化前重新处理授权与品牌。

第一阶段先完成规则核心、自动化测试和可联机的 3D 灰盒竖切，再进入正式美术生产。
